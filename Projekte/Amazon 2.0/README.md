## 💡 Über das Projekt

**Amazon 2.0** ist eine vollständige Re-Implementierung einer modernen Online-Shopping-Plattform. Ursprünglich als monolithisches JavaScript-Skript gestartet, wurde die Plattform im Laufe der Entwicklung komplett refaktoriert und auf eine modulare **TypeScript + Vite**-Architektur migriert.

Das Ziel des Projekts ist es, ein erstklassiges, flüssiges und responsives Einkaufserlebnis ohne externe schwere Frontend-Frameworks zu bieten. Es beinhaltet modernste E-Commerce-Technologien: 45-Minuten Sub-Orbit Frachtraketen Express (Starship Cargo MK-2), Neuro-Feedback Schlaf- & Regenerations-Architekt, Händler DeFi Staking & Liquiditäts-Pools, Geothermie- & Vulkan-betriebene Cloud-Rechenzentren, Neural-Audio Akustik-Hologramm Simulator, Schweizer Freeport Zollfreilager-Manager, 1.000 km/h Hyperloop Express-Rohrpost, Stratosphären-Ballon IoT Relais-Station (HAPS), 3D-Lichtfeld-Display Projektion (Glasses-Free 3D), KI-Multimarker Emotion & Facial Heatmap Tracker, Dezentrale Layer-3 zk-STARK Privacy Rollups, Tiefsee Frachtschiff & AIS-Routen-Radar, Quanten-Internet Teleportations-Key-Exchange (QKD Simulator), Autonome Ground Rover Lieferroboter-Flotte, Bionisches Exoskelett Hebekraft-Assist, Raman Laser Spektrometrie für Luxus-Echtheitsprüfung, AI Smart Solar Energy Grid Logistics, Self-Healing Web3 Garantie Smart Contracts, Digital Olfaction Duft-Protokoll, Brain-Computer-Interface (BCI) Mind-Shopping, Metaverse VR Spatial Commerce & Haptische Handschuhe, Bitcoin Lightning Micro-Payment Streaming (Sats/s), DNA & Biomarker Ernährungs-Konfigurator, Starlink LEO Satelliten-Tracking, Neuro-Adaptives Eye-Tracking & Hands-Free Navigation, Zero-Knowledge Proof (zk-SNARKs) Alters- & Bonitätsprüfung, Cold-Chain IoT Sensor Telemetrie, Multimodale Visual- & Audio-Suche, NIST Post-Quantum Kryptografie (Kyber/Dilithium), automatisierter Cross-Border DDP Zoll- & Steuerrechner, Prime Air Drohnen 3D Flight-Tracker, Biometrischer Health- & Ergonomie-Sync, Dynamic Pricing ML Simulator, WebRTC P2P AirDrop, Smart-Mirror Virtual Dressing Room, Offline-First CRDT Synchronisation, Autonomer KI-Einkaufs-Agent, WASM Video-Review Studio, dezentrales P2P Review Verifizierungs-Netzwerk, NFC & Barcode Scanner, Passkeys, KI-Stimmen, CO₂-Kompensation, Hologramm-Projektor und Raytracing Studio.

## 🚀 Installation & Schnellstart

### 1. Repository klonen & Abhängigkeiten installieren
```bash
git clone https://github.com/Schengii/Amazon2.0.git
cd "Amazon 2.0"
npm install
```

### 2. Umgebungsvariablen einrichten
```bash
# Vorlage kopieren
cp .env.example .env
# Unter Windows PowerShell:
Copy-Item .env.example .env
```

### 3. Entwicklungs-Server starten
```bash
npm run dev
```
Die Anwendung ist nun unter `http://localhost:5173` erreichbar.

### 4. Tests ausführen
```bash
npm test
```
Führt alle 124 Vitest Unit-Tests über 75 Testdateien parallel und isoliert aus.

### 5. Produktion-Build erstellen & prüfen
```bash
npm run build
npm run preview
```

## ☁️ Deployment auf Vercel

Amazon 2.0 ist für das One-Click-Deployment auf **[Vercel](https://vercel.com)** optimiert. Die Routing- und Security-Regeln sind in [vercel.json](file:///c:/Users/sche-/Desktop/Programmieren%20Projekte/Amazon%202.0/vercel.json) hinterlegt.

### Vercel Projekt-Einstellungen:
- **Framework Preset**: `Vite`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install` (oder `npm ci`)

### Features der `vercel.json`:
- **SPA Rewrites**: Leitet alle Routen sauber auf `/index.html` um, verhindert 404-Fehler beim Neuladen.
- **Aggressives Asset-Caching**: Immutable Cache-Header (`max-age=31536000`) für statische Assets im `dist/assets/`-Verzeichnis.
- **Sicherheits-Header**: Aktiviert `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: strict-origin-when-cross-origin` und moderne `Permissions-Policy`.
