🧱 Minecraft C++ Voxel Engine

Eine hoch-performante, modulare 3D-Voxel-Engine in C++20 und OpenGL 4.5

C++20 OpenGL 4.5 CMake 3.20+ Redstone Logik Procedural Generation

Engine Features

  • 🔴 Redstone Logik: Wires, Torches, Levers, Lamps mit Signal-Ausbreitung
  • 🌍 Multi-Biome System: Wüste, Schneeberg, Birkenwald & Höhlen
  • 🌊 Wasser-Physik: Auftrieb, Unterwasser-Nebel-Shader & Schwimmen
  • ☀️ Tag/Nacht-Zyklus: 24.000 Ticks mit flüssiger Farb-Interpolation
  • 🎒 Inventar & Crafting: 36 Slots, Drops & 2x2 Crafting Rezept-Manager
  • 💾 Chunk-Persistence: Binäre Serialisierung in `world_saves/`

Build & Kompilierung

Das Projekt wird mit CMake kompiliert:

# 1. Konfiguration
cmake -B build -S .

# 2. Kompilieren
cmake --build build --config Release

# 3. Spiel starten
.\build\Release\Minecraft.exe
