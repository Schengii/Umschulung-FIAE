💡 Engine Implementation Note

In the C++ engine, shadow calculation uses 3 light-space cascaded matrices ($r=15\text{m}, 40\text{m}, 90\text{m}$) with 3x3 Percentage-Closer Filtering (PCF) and slope-scaled depth bias to eliminate shadow acne.

Engine Architecture & Subsystems

Modular, clean, and decoupling-focused design following modern C++20 conventions.

⚡

Multithreaded Chunk Pipeline

Worker threads generate terrain noise (FastNoiseLite) and build vertex/index arrays without touching the OpenGL context. The main thread performs bounded batch GPU buffer uploads.

  • 16 vertical ChunkSections per chunk
  • Greedy meshing with sub-voxel face culling
  • Asynchronous mesh snapshots across boundaries
🎯

Amanatides & Woo 3D DDA Raycast

Mathematically exact fast voxel traversal algorithm. Guarantees zero sampling gaps and instant hit detection for block placement, continuous mining, and combat.

  • Calculates exact hit surface normals
  • Sub-millimeter bounding box precision
  • Instant interaction across chunk boundaries
🌅

Atmosphere & CSM Shadows

Cascaded Shadow Mapping (3 frustum cascades) rendered to high-resolution depth textures with 3x3 PCF filtering, radial screen-space God-Rays, and ACES filmic tone mapping.

  • Dynamic day, sunset, and night color gradients
  • Procedural cloud layer at $Y = 128$
  • Screen-Space Ambient Occlusion (SSAO)
💾

Anvil Region Save System

Persistence modeled after Minecraft's Anvil format. 32×32 chunks per .mca file with localized sector tables, atomic game state saves, and inventory persistence.

  • Saves chunks only when modified
  • Thread-safe RegionManager singleton
  • Atomic game.dat player data writes
🤖

EnTT ECS & Mob AI

Entity Component System powered by EnTT 3.13. Hierarchical box meshes for mobs, animals, and remote players. 3D A* pathfinding, breeding, and mount riding mechanics.

  • Zombies, Skeletons, Creepers, Spiders, Animals
  • 3-headed Wither boss with explosive projectiles
  • Dead-reckoning client prediction interpolation
🌐

UDP Multiplayer Networking

Non-blocking UDP socket manager supporting Windows Winsock2 and POSIX sockets with replay attack mitigation, sequence counters, and high-frequency delta sync.

  • Cryptographic 64-bit session tokens
  • Main-thread queued packet dispatch
  • Remote player rendering with nametags

Quickstart (Powershell) 
# 1. Configure with CMake
cmake -B build -DCMAKE_BUILD_TYPE=Release

# 2. Build game and test suite
cmake --build build --config Release --target Minecraft
cmake --build build --config Release --target TestEngine

# 3. Run automated tests (111 tests)
.\build\TestEngine.exe

# 4. Launch Minecraft!
.\build\Minecraft.exe
