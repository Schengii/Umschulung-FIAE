Welcome to the Git Sandbox! You can freely type commands or use the buttons below to grow the commit tree.

Befehlsreferenz Command Reference

  • git commit -m "..." Erstellt neuen CommitCreates new commit
  • git branch <name> Erstellt neuen BranchCreates new branch
  • git checkout <name> Wechselt Branch/CommitSwitches branch/commit
  • git checkout -b <name> Erstellt & wechselt BranchCreates & switches branch
  • git merge <name> Mergt Branch in aktuellen HEADMerges branch into HEAD
  • git rebase <name> Rebaset HEAD auf BranchRebases HEAD onto branch
  • git reset --hard <hash> Setzt Branch zurückResets branch back
  • git log Zeigt Commit-HistorieShows commit history
  • clear Konsole leerenClear terminal console
