3. Lokale Speicherung (Local Storage)

3. Local Storage

Diese Website verwendet den localStorage Ihres Browsers, um Ihre Benutzereinstellungen ausschließlich lokal auf Ihrem Endgerät zu speichern. Es findet keine Übertragung an externe Server oder Tracking-Dienste statt:

This website uses your browser's localStorage to keep your personal UI preferences stored exclusively on your device. No data is transmitted to external analytics or tracking services:

  • fiae_theme: Gewähltes Farbschema (Hell / Dunkel)Selected theme (Light / Dark)
  • fiae_accent_color: Gewählte Akzentfarbe (Blau, Grün, Lila, etc.)Selected accent color (Blue, Green, Purple, etc.)
  • fiae_lang: Sprachpräferenz (Deutsch / Englisch)Language preference (German / English)
  • fiae_username: Optional eingegebener Name für die Dashboard-BegrüßungOptionally entered name for personalized greetings
  • fiae_a11y_*: Barrierefreiheits-Einstellungen (Schriftgröße, Legasthenie-Hilfe, Farbkontrast)Accessibility options (Font scale, Dyslexia font, High contrast)
  • fiae_achievements: Lokale Gamification-Errungenschaften & FortschritteLocal achievements & gamification progress
  • snake_highscore, memory_best_time: Lokale Spielstände der Mini-GamesLocal game high scores
  • fiae_cookie_consent: Status der Cookie-/Datenschutz-BestätigungConsent acknowledgement state

Sie können die gespeicherten Daten jederzeit selbst über Ihre Browser-Einstellungen oder den Button „Alle lokalen Daten löschen“ im Dashboard zurücksetzen.

You can clear this stored data anytime in your browser settings or via the reset button on the dashboard.
